# Online Course App (Django) - Exam Feature

Run:
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py seed_data      # creates admin/admin123, learner/learner123, demo course + exam
    python manage.py runserver

- Admin: http://127.0.0.1:8000/admin/
- Courses: http://127.0.0.1:8000/onlinecourse/
